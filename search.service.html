Search Service

Documentación técnica de rutas expuestas por el API Gateway (Gin) y su conexión con el microservicio gRPC de búsqueda.

ENDPOINTS HTTP / GIN

POST

/api/v1/search/users

gRPC: SearchService.SearchUsers

Búsqueda general de perfiles en el sistema por nombre o username.

Request Body (JSON)
{
  "query": "Juan",
  "page": 1,
  "size": 10
}
Response (JSON)
{
  "users": [
    {
      "id": "672800e46f4b3358a701fa9c",
      "username": "juanp",
      "title": "Juan Pérez",
      "avatar": "https://storage.googleapis.com/.../avatar.jpg",
      "birthdate": "2000-01-01"
    }
  ],
  "total": 1,
  "has_next_page": false
}
POST

/api/v1/search/chats

gRPC: SearchService.SearchChatUsers

Búsqueda enfocada al autocompletado para chats, aplicando restricciones de edad, roles y bloqueos.

Nota de Arquitectura: Gestionado en el controlador search.SearchController.SearchChatUsers-fm a través del API Gateway.
Request Body (JSON)
{
  "query": "Ana",
  "size": 15
}
Response (JSON)
{
  "users": [
    {
      "id": "6727ea0d6f4b3358a701dd7d",
      "username": "anag",
      "title": "Ana García",
      "avatar": "https://storage.googleapis.com/.../ana.jpg",
      "user_id": "6727ea0d6f4b3358a701dd7d"
    }
  ]
}

POST

/api/v1/search/comments

gRPC: SearchService.SearchComments

Búsqueda de texto dentro de comentarios asociados a posts o stories mediante target_id y target_type.

Request Body (JSON)
{
  "query": "excelente",
  "page": 1,
  "size": 10
}
Response (JSON)
{
  "comments": [
    {
      "id": "67a1b2c3d4e5f67890123500",
      "comment": "Excelente aportación.",
      "post_id": "67a1b2c3d4e5f67890123499",
