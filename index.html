Documentación API Chat & WebSockets

Especificación oficial, 100% verificada mediante el código fuente del backend en Go (patrón Command / Response) y logs de ejecución reales.

RESUMEN DE ARQUITECTURA DE COMUNICACIÓN

Acción Emitida (Cliente ➔ Servidor) Mecanismo de Respuesta / Evento Escuchado Alcance / Receptor
chat.get_chat_list Evento "response" Cliente Emisor (Solicitante).
chat.get_chat_messages Evento "response" Cliente Emisor (Solicitante).
chat.send_message Evento "response" (al emisor) + Evento "chat.message" (a la sala) Emisor (ACK) y Sala de Chat (Tiempo real).
chat.edit_message Evento "response" Cliente Emisor (Solicitante).
chat.delete_message / chat.delete_chat Evento "response" Cliente Emisor (Solicitante).
chat.delete_messages Evento "response" Cliente Emisor (Solicitante).
chat.start_typing / chat.stop_typing Evento "chat.typing_status" Únicamente al target_user_id.
presence.watch Evento "presence.snapshot" Cliente Solicitante.

1. PETICIONES Y RESPUESTAS (EVENTO "response")

Estas acciones se envían mediante socket.emit(evento, data) y el servidor devuelve su resultado emitiendo el evento global socket.on("response", ...).

chat.get_chat_list ➔ Respuesta vía: "response"

Obtiene la lista resumida de conversaciones activas del usuario.

1. Emisión del Cliente:
// socket.emit("chat.get_chat_list", { ... })
{
  "user_id": "672800e46f4b3358a701fa9c",
  "before_chat_id": "",
  "limit": 10
}
2. Respuesta del Servidor (socket.on("response")):
{
  "type": "response",
  "payload": {
    "chats": [
      {
        "chat_id": "6a022c0a50bf64cf1674e287",
        "contact": {
          "profile_id": "672800e46f4b3358a701fa9d",
          "user_id": "672800e46f4b3358a701fa9c",
          "avatar": "https://storage.googleapis.com/media-temp.cuboconecta.com/avatars/1778611747_media.jpg",
          "name": "Carlos Santana",
          "last_message": "Esta es una prueba",
          "created_at": "2026-07-22T20:14:37.218Z"
        }
      }
    ],
    "has_more": false
  }
}

chat.delete_message ➔ Respuesta vía: "response"

Elimina un mensaje específico de la conversación.

1. Emisión del Cliente:
// socket.emit("chat.delete_message", { ... })
{
  "message_id": "67a1b2c3d4e5f67890123457",
  "chat_id": "6a022c0a50bf64cf1674e287",
  "user_id": "672800e46f4b3358a701fa9c"
}
2. Respuesta del Servidor (socket.on("response")):
{
  "type": "response",
  "payload": {
    "message_id": "67a1b2c3d4e5f67890123457",
    "chat_id": "6a022c0a50bf64cf1674e287",
    "deleted": true
  }
}

chat.delete_chat ➔ Respuesta vía: "response"

Elimina un chat completo para el usuario solicitante.

1. Emisión del Cliente:
// socket.emit("chat.delete_chat", { ... })
{
  "chat_id": "6a022c0a50bf64cf1674e287",
  "profile_id": "672800e46f4b3358a701fa9d"
}
2. Respuesta del Servidor (socket.on("response")):
{
  "type": "response",
  "payload": {
    "chat_id": "6a022c0a50bf64cf1674e287",
    "deleted": true
  }
}

chat.delete_messages ➔ Respuesta vía: "response"

Elimina mensajes individuales o por lote. Si delete_for_everyone es true, elimina el mensaje para todos los miembros del chat (válido únicamente dentro de los primeros 10 minutos desde su envío). Si es false, solo se oculta para el usuario que realiza la petición.

1. Emisión del Cliente:
// socket.emit("chat.delete_messages", { ... })
{
  "chat_id": "6a022c0a50bf64cf1674e287",
  "user_id": "672800e46f4b3358a701fa9c",
  "message_ids": [
    "67a1b2c3d4e5f67890123457",
    "67a1b2c3d4e5f67890123458"
  ],
  "delete_for_everyone": true
}
2. Respuesta del Servidor (socket.on("response")):
{
  "type": "response",
  "payload": {
    "success": true,
    "deleted_count": 2,
    "deleted_message_ids": [
      "67a1b2c3d4e5f67890123457",
      "67a1b2c3d4e5f67890123458"
    ]
  }
}

chat.start_typing / chat.stop_typing Acción

Notifica el estado de escritura del usuario. Requiere target_user_id.

Petición (Cliente ➔ Servidor):
// socket.emit("chat.start_typing", { ... })
{
  "chat_id": "6a022c0a50bf64cf1674e287",
  "user_id": "6727ea0d6f4b3358a701dd7d",
  "target_user_id": "672800e46f4b3358a701fa9c"
}

3. EVENTOS DE PRESENCIA

presence.snapshot Presencia

Solicita la presencia de un listado de usuarios.

Petición (Cliente ➔ Servidor):
// socket.emit("presence.snapshot", { ... })
{
  "user_ids": [
    "672800e46f4b3358a701fa9c",
    "6931d2081be27e64d77a0059"
  ]
}
Respuesta Recibida (socket.on("presence.snapshot")):
{
  "data": {
    "672800e46f4b3358a701fa9c": true,  // En línea
    "6931d2081be27e64d77a0059": false  // Desconectado
  }
}

presence.watch Presencia

Suscripción en tiempo real a la presencia de un usuario específico.

Petición (Cliente ➔ Servidor):
// socket.emit("presence.watch", { ... })
{
  "user_id": "6931d2081be27e64d77a0059"
}
