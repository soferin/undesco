Resumen de Arquitectura de Eventos

Acción Emitida (Cliente) Mecanismo / Evento de Respuesta Alcance / Receptor
chat.get_chat_list Evento "response" Cliente Emisor (Solicitante)
chat.get_chat_messages Evento "response" Cliente Emisor (Solicitante)
chat.send_message "response" (ACK) + "chat.message" (Stream) Emisor y Sala de Chat
chat.edit_message Evento "response" Cliente Emisor (Solicitante)
chat.delete_messages Evento "response" Cliente Emisor (Solicitante)

presence.watch Suscripción pasiva Cliente Solicitante

1. PETICIONES Y RESPUESTAS (EVENTO "response")

Estas acciones se envían mediante socket.emit(evento, data) y el servidor devuelve su resultado emitiendo el evento global socket.on("response", ...).

EMIT

chat.get_chat_list

Obtiene la lista resumida de conversaciones activas del usuario.

{
  "user_id": "672800e46f4b3358a701fa9c",

  "limit": 10
}

chat.edit_message

Edita el contenido de un mensaje existente, siempre y cuando no hayan transcurrido más de 3 minutos desde su creación. Devuelve la entidad actualizada dentro del payload con los sellos de tiempo en formato Protobuf Timestamp (seconds y nanos).

⚠️
Restricción: Solo se permite editar un mensaje dentro de los primeros 3 minutos (180 segundos) posteriores a su envío (created_at). Si se intenta editar después de este lapso, el servidor rechazará la solicitud devolviendo un error.
1. Emisión del ClienteJSON
{
  "message_id": "6a6145b055502227402bc597",

}

EMIT

chat.delete_messages

Elimina uno o varios mensajes (acepta un arreglo de IDs). Si delete_for_everyone es true, elimina los mensajes para todos los miembros del chat (válido únicamente dentro de los primeros 10 minutos desde su envío). Si es false, solo se ocultan para el usuario que realiza la petición.

⚠️
Restricción: Solo se permite eliminar un mensaje para todos dentro de los primeros 10 minutos (600 segundos) posteriores a su envío (created_at). Si se intenta eliminar después de este lapso, el servidor rechazará la solicitud devolviendo un error.
1. Emisión del ClienteJSON
{
  "chat_id": "6a022c0a50bf64cf1674e287",
  "user_id": "672800e46f4b3358a701fa9c",
  "message_ids": [
    "67a1b2c3d4e5f67890123457",
    "67a1b2c3d4e5f67890123458"
  ],
  "delete_for_everyone": true
}
2. Respuesta del Servidor (socket.on("response"))JSON 
{
  "type": "response",
  "payload": {
    "success": true,
    "deleted_count": 2,
    "deleted_message_ids": [
      "67a1b2c3d4e5f67890123457",
      "67a1b2c3d4e5f67890123458"
    ]
  }
}
EMIT

chat.delete_chats

Elimina uno o varios chats (acepta un arreglo de IDs) para el usuario actual, con opción de eliminar para todos los participantes.

1. Emisión del ClienteJSON
{
  "user_id": "672800e46f4b3358a701fa9d",
  "chat_ids": [
    "6a022c0a50bf64cf1674e287",
    "7b133d1b61ca75da2785f398"
  ],
  "delete_for_everyone": false
}
2. Respuesta del Servidor (socket.on("response"))JSON 
{
  "type": "response",
  "payload": {
    "success": true,
    "deleted_count": 2,
    "deleted_chat_ids": [
      "6a022c0a50bf64cf1674e287",
      "7b133d1b61ca75da2785f398"
    ]
  }
}

  "user_id": "6727ea0d6f4b3358a701dd7d",
  "target_user_id": "672800e46f4b3358a701fa9c"
}

presence.snapshot

  "user_ids": [
    "672800e46f4b3358a701fa9c",
    "6931d2081be27e64d77a0059"
  ]
}
Respuesta Recibida (socket.on("presence.snapshot"))JSON 
{
  "data": {
    "672800e46f4b3358a701fa9c": true,
    "6931d2081be27e64d77a0059": false
  }
}
