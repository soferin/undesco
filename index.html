WebSocket API - Chat

Evento: chat.get_chat_list

Obtiene la lista de conversaciones de un usuario con soporte para paginación.

Request

{
  "user_id": "672800e46f4b3358a701fa9c",
  "before_chat_id": "6a0218f86ea60e4bf5b0a249",
  "limit": 10
}

Parámetros

CampoTipoRequeridoDescripción
user_idstringSíIdentificador del usuario propietario de los chats
before_chat_idstringNoCursor para paginación
limitnumberSíNúmero máximo de chats

Response

{
  "chats": [
    {
      "chat_id": "6a4828b851be3b4af3f7c247",
      "contact": {
        "profile_id": "67d43d6b8f92136e4cfa0b89",
        "user_id": "67d43d6b8f92136e4cfa0b88",
        "avatar": "",
        "name": "Raúl Puentes Aguirre",
        "last_message": "Hola...",
        "created_at": "2026-07-03T21:25:12.258Z"
      }
    }
  ],
  "has_more": true
}
