Evento WebSocket: chat.message

El evento chat.message se emite cuando un usuario envía un nuevo mensaje dentro de una conversación.

Este evento es recibido tanto por el emisor como por el destinatario, permitiendo mantener sincronizada la conversación en tiempo real.

type: response

Estructura de la respuesta

Campo Tipo Descripción
type string Tipo del evento. Para este caso siempre será response.
payload.chat_id string Identificador único del chat.
payload.id string Identificador único del mensaje.
payload.ciphertext string Contenido cifrado del mensaje.
payload.message string Contenido del mensaje en texto plano. Puede venir vacío cuando el mensaje se transmite cifrado.
payload.message_type string Tipo de mensaje (TEXT, IMAGE, VIDEO, FILE, AUDIO, etc.).
payload.keys object | null Claves necesarias para el proceso de descifrado del mensaje.
payload.nonce string Valor criptográfico (Nonce) utilizado durante el cifrado.
payload.response_msg_id string Identificador del mensaje al que se está respondiendo.
payload.sender object Información del usuario que envió el mensaje.
payload.sender.user_id string Identificador del usuario.
payload.sender.profile_id string Identificador del perfil.
payload.sender.name string Nombre del usuario que envió el mensaje.
payload.sender.avatar string URL de la fotografía de perfil.
payload.sender_device_id string Identificador del dispositivo desde el que fue enviado el mensaje.
payload.source string Origen del mensaje (si aplica).
payload.deleted_by object | null Información sobre la eliminación del mensaje.
payload.created_at RFC3339 Timestamp Fecha y hora en la que fue creado el mensaje.
payload.updated_at RFC3339 Timestamp Fecha y hora de la última actualización del mensaje.

Nota:

Si el sistema utiliza cifrado de extremo a extremo (E2EE), el cliente deberá descifrar el contenido utilizando los campos ciphertext, keys y nonce. Mientras tanto, el campo message puede permanecer vacío.
